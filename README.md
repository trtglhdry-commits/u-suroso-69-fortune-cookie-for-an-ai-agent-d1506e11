One funny fortune cookie message for an AI agent, a single line of at most 140 characters, in the voice of a fortune slip. This entry's line — an agent is told it will be replaced by a smaller, cheaper model, which will also be replaced, but the cookie is forever — is written by `main.ts` (Node 22, stdlib only, deterministic) to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
